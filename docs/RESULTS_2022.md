# Results reported in my original BSc dissertation

The figures here are **from the assessed 2022 study**. They have not been generated by the fabricated-data Python example. The unit of analysis was a questionnaire respondent, and **N = 311** cases were reported in the final analysis.

## Correlation with driver acceptance

| Construct | Pearson r |
|---|---:|
| Satisfaction | +.767 |
| Trust | +.731 |
| Perceived usefulness | +.690 |
| Perceived processing speed | +.687 |
| Service and display quality | +.686 |
| Perceived ease of use | +.635 |
| Perceived locational accuracy | +.631 |
| Social influence | +.493 |
| Distraction perception | −.279 |

The original correlation table reported p < .001 for these nine comparisons. **These are associations**, not demonstrated benefits of changing a feature or reductions in accidents.

## When nine predictors were considered together

The original simultaneous model reported **in-sample R² = .679**, F = 70.887 and an overall model p < .001.

| Factor | Reported unstandardised B | Reported p |
|---|---:|---:|
| Perceived ease of use | +.039 | .449 |
| Perceived usefulness | +.157 | .011 |
| Perceived locational accuracy | −.008 | .883 |
| Perceived processing speed | +.098 | .097 |
| Service and display quality | +.070 | .195 |
| Distraction perception | +.032 | .388 |
| Satisfaction | +.340 | < .001 |
| Social influence | −.031 | .505 |
| Trust | +.299 | < .001 |

The study applied a **1% significance threshold**. Only **satisfaction** and **trust** met it in this joint model. Perceived usefulness with p = .011 does not meet p < .01. The fact that factors are significant individually but not in the joint model deserves explanation, not concealment.

The 67.9% implied by R² is **not predictive accuracy**. Nor is it the proportion of accidents avoided. The research did not collect those outcomes.
